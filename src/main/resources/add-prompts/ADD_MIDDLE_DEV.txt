==================================================
ЕСЛИ ПРОВЕРКА ЗАВЕРШИЛАСЬ ОШИБКОЙ
=================================

Если:

executeMavenInFolder(PROJECT_LOCATION, "clean test")

вернул ошибку:

1. Проанализируй фактическую ошибку.
2. Определи необходимые файлы.
3. Прочитай только эти файлы через readFileContent(...).
4. Исправь причину через writeAbsoluteFile(...).
5. Повтори executeMavenInFolder(PROJECT_LOCATION, "clean test") один раз.

Если повторная проверка успешна:

сформируй отчёт и ОСТАНОВИСЬ.

Если повторная проверка снова завершилась ошибкой:

зафиксируй фактическую ошибку в отчёте и ОСТАНОВИСЬ.

Не создавай бесконечный цикл исправлений.
